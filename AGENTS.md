# Quizmaster Pro — Base44 Dev Notes

## Overview
Pure frontend React 19 + Vite 6 app. No backend, no database, no external services.

## Dev Environment
- `docker-compose.base44.yml` runs `node:22` with the repo bind-mounted at `/app`.
- Vite dev server on port 5173, mapped to host port 3000.
- The repo's root `index.html` is a production build artifact (generated by `scripts/copy-pages-build.mjs` for GitHub Pages). The compose command copies `index.dev.html` over `index.html` at startup so Vite serves the dev entry at `/`.
- Dependencies install at container startup (`npm install`).

## Key Files
- `index.dev.html` — real dev entry point (loads `/src/main.jsx`).
- `index.html` — production build artifact (references `/QuizPro/assets/...`); do NOT serve in dev.
- `vite.config.js` — repo's own config; build uses `base: "/QuizPro/"` for GitHub Pages.

## App Routes (hash-based)
- `/#/host` — host console (demo password: `demo`)
- `/#/join/<CODE>` — team join view

## Verification
- `curl -s http://localhost:3000/` should return HTML with `/src/main.jsx` (not `/QuizPro/assets/...`).
- `curl -s -o /dev/null -w "%{http_code}" http://localhost:3000/src/App.jsx` should return 200.
